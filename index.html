          الخطوة 3 من 3 — الخطوة الأخيرة
        


        

          الخطوة الأخيرة: انسخ البرومبت الجاهز وأرفق الصورتين لوكيلك الذكي
        


        

          تم حقن بياناتك بنجاح داخل البرومبت الرئيسي! الآن انسخ البرومبت الجاهز بالأسفل، وحمّل الصورة المرجعية REFERENCE_IMAGE.JPG، وأرفقهما مع صورتك الشخصية باسم USER_PHOTO لوكيل الذكاء الاصطناعي الخاص بك.
        


        
        

          
          

            

              1. البرومبت الجاهز
              
نسخ البرومبت النهائي المحقون

              
تم دمج ألوانك وعناوينك ومهاراتك داخل القالب الرئيسي بنجاح.

            

            
          


          
          

            

              2. الصورة المرجعية
              
تحميل REFERENCE_IMAGE.JPG

              
حمّل هذه الصورة المرجعية وأرفقها مع البرومبت ليبني الوكيل نفس التصميم.

              

                
                REFERENCE_IMAGE.JPG

            نموذج التصميم المرجعي (11 قطعة فنية متكاملة)
            
          

        

      


      
      

        

        

        
      


      
      

        

          

            
1. استخرج تفاصيل هويتك بصيغة JSON من وكيلك الذكي

            

              انسخ هذا البرومبت وأرسله لوكيل الذكاء الاصطناعي الذي يعرفك (أو أرفق معه سيرتك الذاتية CV). سيقوم الوكيل بإعطائك كود JSON جاهز يحتوي على ألوانك وعناوينك ومهاراتك.
            

          

          
        


        

          

            
1

            

              
انسخ البرومبت بالأسفل

              
اضغط زر النسخ ليتم نسخ برومبت (Personal Brand Details JSON) بالكامل بضغطة واحدة.

            

          


          

            
2

            

              
أرسله لوكيلك الذكي

              
افتح ChatGPT أو Claude أو Gemini والصق البرومبت (وإن لم يكن يعرفك مسبقاً أرفق له سيرتك الذاتية أو نبذة عنك).

            

          


          

            
3

            

              
انسخ النتيجة وانتقل للخطوة 2

              
سيعطيك وكيلك نتيجة بين قوسين { ... } بصيغة JSON، انسخها ثم انتقل للخطوة الثانية هنا.

            

          

        


        
        

          روابط سريعة لفتح وكيلك الذكي بعد النسخ:

3. حقيبتك جاهزة للتوليد! أرسل هذه الـ 3 عناصر لوكيلك الذكي

            

              تم حقن بياناتك بنجاح داخل البرومبت الرئيسي (MASTER PROMPT). كل ما عليك الآن هو إرسال (البرومبت النهائي + الصورة المرجعية REFERENCE_IMAGE.JPG + صورتك الشخصية باسم USER_PHOTO) في رسالة واحدة لوكيلك الذكي، وسيتكفل هو بتصميم الحقيبة الكاملة لك!

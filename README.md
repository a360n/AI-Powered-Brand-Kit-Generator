## How It Works (Guided 3-Step Flow)

1. **Overview & Introduction:**
   Explains the complete workflow and previews the 11-asset reference branding system before starting.
2. **Step 1 — Extract Your Brand Details (JSON):**
   Copy the [`Personal_Brand_Details_JSON_Prompt.md`](./Personal_Brand_Details_JSON_Prompt.md) prompt in one click and send it to your AI assistant (ChatGPT, Google Gemini, or Claude) to receive a structured JSON object containing your verified brand colors, headlines, bio, and core skills.
3. **Step 2 — Paste Output & Automatic Compatibility Verification:**
   Paste the JSON output into the verification field. The tool automatically validates schema compatibility in real time and extracts your variables (with an optional visual no-code editor and color pickers in the full workspace).
4. **Step 3 — Copy Injected Master Prompt & Reference Assets:**
   The web app automatically injects your extracted brand details into [`MASTER PROMPT — AI PERSONAL BRANDING DESIGN SYSTEM.md`](./MASTER%20PROMPT%20%E2%80%94%20AI%20PERSONAL%20BRANDING%20DESIGN%20SYSTEM.md) and provides:
   - One-click copy for the ready, customized Master Prompt.
   - Direct download for [`REFERENCE_IMAGE.JPG`](./REFERENCE_IMAGE.JPG).
   - Clear specifications and a client-side helper to automatically rename your personal photograph to `USER_PHOTO`.
   - A completion button that opens the full interactive workspace.

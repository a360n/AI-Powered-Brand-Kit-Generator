## 🚀 كيف يعمل الموقع؟ (How It Works in 3 Simple Steps)

1. **الخطوة الأولى (استخراج الهوية بصيغة JSON):**
   ينسخ المستخدم برومبت [`Personal_Brand_Details_JSON_Prompt.md`](./Personal_Brand_Details_JSON_Prompt.md) بضغطة زر ويرسله لوكيل الذكاء الاصطناعي الخاص به (ChatGPT / Gemini / Claude) ليحصل على ملف `JSON` دقيق بهويته وألوانه ومهاراته.
2. **الخطوة الثانية (لصق النتيجة والمراجعة التفاعلية):**
   يلصق المستخدم مخرجات الـ `JSON` في الموقع، ليقوم المحلل الذكي بقراءتها وعرضها في محرر مرئي تفاعلي (مع منتقي ألوان Color Pickers وحقول مرئية قابلة للتعديل لغير التقنيين).
3. **الخطوة الثالثة (توليد البرومبت النهائي المحقون + المرفقات):**
   يقوم الموقع بحقن بيانات المستخدم تلقائياً داخل [`MASTER PROMPT — AI PERSONAL BRANDING DESIGN SYSTEM.md`](./MASTER%20PROMPT%20%E2%80%94%20AI%20PERSONAL%20BRANDING%20DESIGN%20SYSTEM.md)، ويوفر للمستخدم:
   - زر نسخ البرومبت النهائي المحقون ببياناته.
   - زر تحميل الصورة المرجعية [`REFERENCE_IMAGE.JPG`](./REFERENCE_IMAGE.JPG).
   - إرشادات وأداة مساعدة محلية لتجهيز وتسمية صورته الشخصية باسم `USER_PHOTO`.
